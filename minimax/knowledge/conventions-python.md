# 工程规范：Python 代码风格与提交要求

## 代码风格

- 目标 Python 3.11+，使用 `from __future__ import annotations` 保持注解惰性求值
- 类型注解必须写全公共方法的参数与返回值
- 不引入新的第三方运行时依赖；只允许标准库
- 不允许使用后台线程、`atexit` 钩子、定时器实现业务语义；时间相关逻辑必须可注入、可测试

## 测试要求

- 每个对外方法至少一条正向用例 + 一条边界用例
- 既有用例的断言不允许为了「让新代码通过」而修改；如需变更契约，先改规格文档再改用例
- 修改后必须全量跑 `pytest`，历史用例必须 100% 通过

## 提交要求

- 提交信息格式：`<scope>: <动词> <对象>`，例如 `inventory: add reservation ttl`
- 变更必须附带「改了什么」与「哪些行为必须保持不变」两段说明
- 涉及状态机变更时，必须同步更新规格文档中的状态机小节
