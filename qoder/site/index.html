智研助手
把论文和笔记，变成能追问的知识库

导入论文摘要、课程笔记或零散资料，用自然语言直接提问。系统用 seekdb 做语义检索找到最相关的段落， 再结合大模型生成带出处的回答，并通过 PowerContext 记住你的偏好与历史提问。

要解决的痛点

和身边同学聊下来，重复耗时的环节集中在三件事上

1

文献读不完，找不到结论

下载几十篇论文，真正写综述时只记得「好像在哪篇看到过」，只能一篇篇翻。

2

笔记散落，复习时检索无能

笔记分散在文档、聊天记录和截图里，关键词对不上就彻底找不回来。

3

每次提问都要重新交代背景

通用问答工具不记得你研究什么方向、上次问过什么，上下文每次从零开始。

核心功能

四步闭环：导入 → 索引 → 检索 → 带出处回答

文档导入与自动切块

粘贴论文摘要或笔记，按语义切分成段落，向量化后写入 seekdb。

seekdb 语义检索

问题向量化后做 HNSW 余弦检索，取最相关的 5 个段落作为回答依据。

带出处的回答

回答中标注资料编号，正文下方列出命中的原始段落，可逐条回溯核对。

记忆与偏好复用

PowerContext 保存历史问答与用户偏好，下次提问自动注入，不用重复交代背景。

历史交互回看

侧栏展示最近的问答记录，点击刷新即可从记忆服务重新拉取。

纯本地数据

文档与向量都存在自己的 seekdb 里，不依赖第三方知识库服务。

技术组成

每个组件都在主流程里承担具体职责，不是装上去凑数

Qoder
功能开发与站点发布
seekdb
向量存储与语义检索
PowerContext
用户偏好与历史记忆
MiniMax
基于检索结果生成回答
检索链路：问题 → embedding（MiniLM 384 维）→ seekdb HNSW 余弦检索 Top-5 → 拼装上下文 → 大模型生成带引用回答 → 写入记忆。

界面预览

实际界面以本地运行版本为准

1. 导入文献 / 笔记

标题（可选）：机器学习综述
粘贴论文摘要、笔记内容…
导入并索引 已索引 3 个段落

2. 智能问答

输入问题，如：机器学习的主要应用有哪些？

验证样例

评审可按这三步复现主流程

导入

粘贴一段关于「机器学习应用」的文本 → 点击导入，返回「已索引 N 个段落」。

提问

输入「机器学习有哪些应用？」→ 返回带 [1] [2] 引用编号的回答，下方列出命中的原始段落。

记忆复用

刷新历史区域，能看到刚才的问答记录；再次提问时，用户偏好会被自动带上。

本地运行

需要 Python 3.11+、MiniMax API Key，以及一个能连到的 seekdb；PowerContext 用于记忆与偏好

# 安装依赖（所有平台相同）
cd backend
pip install -r requirements.txt

# Linux / Apple Silicon macOS：嵌入式 seekdb，数据落在本地目录
export MINIMAX_API_KEY="你的 Key"
export POWERCONTEXT_BASE=http://127.0.0.1:8001
export SEEKDB_EMBEDDED=1
export SEEKDB_PATH=../seekdb-data
python main.py

# Windows / Intel macOS：装不上嵌入式原生库，先用 Docker 起 seekdb
docker run -d --name seekdb -p 2881:2881 -v seekdb-data:/var/lib/oceanbase oceanbase/seekdb:latest
# PowerShell 用 $env:变量名，cmd 用 set，变量名相同
export MINIMAX_API_KEY="你的 Key"
export POWERCONTEXT_BASE=http://127.0.0.1:8001
export SEEKDB_HOST=127.0.0.1
export SEEKDB_PORT=2881
python main.py

# 打开界面
open http://localhost:8000/static/index.html
没有网络装不上向量模型时，加 EMBEDDING_BACKEND=hash 即可跑通导入到回答的完整流程，代价是检索质量会下降，正式使用请保持默认的 minilm。 完整说明（依赖版本、seekdb 与 PowerContext 接入方式、接口列表）见代码仓库中的 qoder/README.md。
